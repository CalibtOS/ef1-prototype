# eFactory Deck — scratchpad

Audience: Berat (owner eFactory, co-owner CalibtOS). Visual thinker, ex-consultant. Fear = losing freedom/control. Objection = "why change if it works?"
Duration: ~35–40 min, 17 core slides. Dark charcoal executive deck. Teal = structure, green=built, blue=designed, amber=decision.

## System
- Font: IBM Plex Sans (body/titles) + IBM Plex Serif (big stat numbers only). Avoids Inter trope, spec-permitted.
- All-dark deck for cohesion; data exhibits use surface/paper panels on dark, not a separate light theme.
- Status chip = dot + label, colored by built/designed/decision. Never raw emoji.
- Archetypes per design system spec, one per slide. Sparse text; detail → speaker notes.
- Numbers: only real screenshot figures (3,410 deals · 4,159/5,000 slots · 5,262 leads). 6–10 hrs/wk labelled conservative estimate. Prototype = "proves the workflow", not live.
